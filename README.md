# stardust-sai-monitor

Code, derived data and reproduction scripts for

> Kushnir, D. (2026), *Design of a dedicated solar-occultation satellite for
> monitoring stratospheric aerosol injection: detection thresholds, the
> trace-gas floor, and latitude-resolved performance*, Atmos. Meas. Tech.
> (in review).

Every figure, table and quoted number in the paper regenerates from this
repository **without downloading any external data**: the third-party
datasets the analysis rests on (GloSSAC, ACE-FTS residual spectra, the ACE
atlas, HITRAN) are shipped only as the small derived extracts the paper
actually uses, each documented in `data/PROVENANCE.md`, and the scripts in
`fetch/` rebuild those extracts from the originals for anyone who wants the
full chain.

## Install

```bash
git clone https://github.com/DoronKushnir/stardust-sai-monitor.git
cd stardust-sai-monitor
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pytest -q                      # ~1 min: package + shipped data sanity checks
```

Python >= 3.10, pure Python (numpy, scipy, matplotlib, netCDF4, pyyaml);
`hitran-api` is needed only for the full raw-data chain (`fetch/README.md`).
The repository is about 180 MB, almost all of it the derived data in
`data/` (`data/PROVENANCE.md`). Run everything from the repository root.

## Reproduce the paper

```bash
python make_all.py --fast      # all figures and tables from the shipped archives, ~15 min
python make_all.py --full      # recompute every archived result first (several hours)
python make_all.py --list      # the steps, what each produces, and its runtime
python make_all.py --only fig4 fig5
```

`--fast` redraws every figure and table from the archived intermediate
results in `outputs/` (the state they had when the paper was compiled) and
recomputes the fast analyses. `--full` reruns the heavy analyses in
dependency order: the detection thresholds and Fisher inputs (Sects. 2–3),
the ACE-FTS residual-floor pipeline (Appendix E), the sensitivity and
two-dimensional studies (Sect. 6, Appendix F), and the trace-gas budget
(Appendix D). The results land in `outputs/`, `figures/` and `tables/`;
`reference_outputs/` holds the versions used in the paper for comparison
(`python reproduce/compare_reference.py`).

## Layout

```
saimon/            the forward model and analysis package
  config.py        data/output locations (SAIMON_ROOT override)
  atmosphere.py, geometry.py             US-standard atmosphere, slant paths
  mie.py, psd.py, aerosol_mie.py         Mie extinction over lognormal PSDs
  materials.py, refractive_index.py      optical constants (silica, calcite, dolomite, alumina, H2SO4)
  sulfate_background.py, backgrounds.py  calibrated two-component sulfate background
  sai.py, sai_2d.py                      injected solid-aerosol layers (1-D and zonal 2-D)
  trace_gases.py, o3_removal.py          HITRAN cross sections, optimal-estimation gas co-retrieval
  glossac.py, glossac_profiles.py        GloSSAC access
reproduce/         one script per figure/table/number of the paper (see make_all.py --list)
  ace_floor/       the ACE-FTS residual-floor pipeline (Appendix E), self-verifying archive
data/              shipped derived data (CC BY 4.0), see data/PROVENANCE.md
outputs/           archived intermediate results (regenerated by --full)
figures/, tables/  the paper's figures and tables (regenerated by --fast)
reference_outputs/ the versions used in the paper
fetch/             obtaining and reducing the original datasets (full chain)
tests/             pytest suite
examples/          small worked examples (slant optical depths, thresholds for a custom PSD)
guide/             the guide: model, assumptions, data, and how the results map to the paper
```

## What the numbers depend on

The detection thresholds use the calibrated two-component sulfate background
(GloSSAC 525-nm amplitude and profile at 20–25°N, microphysics fitted to the
ACE-FTS mid-infrared record), the Fisher-matrix marginalization of Appendix
C, per-element mid-infrared floors that carry the design's own optimal-
estimation gas-removal budget at the 8.80 µm element (Appendix D) with the
wavelength dependence measured on the ACE-FTS residual record (Appendix E),
and the SAGE III/ISS Level-2 visible/NIR uncertainties. The element grid is
centred on the 8.80 µm silica resonance (elements 8.00, 8.10, … 13.20 µm; the
7.8–9.3 µm window 7.80 … 9.20 µm), and every optical-depth floor is converted
to a per-shell extinction with the exact onion-peel gain of the edge-bounded
retrieval grid (`saimon/onion_peel.py`, g = 1.10). Headline single-sounding
thresholds at 20 km: 0.102 Tg (8–13 µm band), 0.141 Tg (window subset).

## Revision history

* **Rounds 53–54 (referee report RC1, September 2026).** Edge-grid exact
  onion-peel gain (was the centre-grid two-term 1.24); the design budget as
  the floor anchor everywhere (was the measured ACE floor); the element grid
  centred on 8.80 µm (new floor archive `data/ace_floor/w0p1_c880/`);
  enlarged-background-family rows, an injection-recovery (spike) test, the
  trials-factor/false-alarm analysis, the slant-ozone latitude check and the
  coherent-vs-independent conversion of the floor added. Thresholds moved from
  0.081/0.115 to 0.102/0.141 Tg; `reference_outputs/` holds the new versions
  (the round-51 versions are in the git history, commit 6f66a83).
